================================================================
  Combine Excel Tabs — Instruction
================================================================

----------------------------------------------------------------
  FOR USERS
----------------------------------------------------------------

PURPOSE
  Picks sheets from several Excel files in the same folder and
  puts them together in one new workbook, in the order you type.

  Replaces opening each file and using Move or Copy Sheet one
  by one.

STEP 1: Prepare Folder
  Put these in the SAME folder:
    - Combine Excel Tabs.py
    - The Excel files to take sheets from (.xls / .xlsx / .xlsm / .xlsb)

  You can keep the source files open in Excel while it runs.
  The script uses its own hidden copy of Excel and does not
  touch the Excel you are working in.

STEP 2: Run
  Double-click: Combine Excel Tabs.py

STEP 3: Select Files
  Every Excel file in the folder is listed with a letter:

    Select FILES:
    e.g. a, c   or   a-c

       [a] "Bank Balance Report FY2026.xls"
       [b] "Bank Guarantee Report FY2026.xls"

    --------------------------------------------------------
    [Enter] Select all
    [#] Select
    [0] Exit

    Files:

  Type    a, c    for files a and c
          a-c     for files a, b and c
  Press [Enter] alone for all files.

  Only the files you pick are opened, so this step is quick
  even when the folder has many files.

STEP 4: Select Sheets
  The visible sheets of the chosen files are listed. Each
  file KEEPS its letter from Step 3 (pick a and c, and the
  codes are a1, a2... and c1, c2..., not b).

       [b] "Bank Guarantee Report FY2026.xls"
          [b1] May26
          [b2] Imp LC May26
          [b3] Exp LC May26
          ...

  Input:
    a1            one sheet
    a3-4          range in one file (a3, a4) - same as a3-a4
    a             every sheet of file a
    a3-4, b12, c12   any mix
  Press [Enter] alone for every sheet of every chosen file.
  [0] goes back to Step 3.

  Sheets are copied in the ORDER you type them. Commas and
  spaces both work as separators. A sheet typed twice is
  copied once.

  A typing mistake redraws the screen with the reason, e.g.
    Error: Invalid Input - range 'a4-a1' must be ascending

STEP 5: Confirm
  The final list is shown, with any renamed sheets and the
  output name:

    Sheets: 4
       1. "Bank Balance Report FY2026.xls"!May26
       2. "Bank Guarantee Report FY2026.xls"!May26   ->   "May26_1"
       3. "Bank Guarantee Report FY2026.xls"!Imp LC May26
       4. "Bank Guarantee Report FY2026.xls"!Exp LC May26

    Output : "Combined_20261117.xlsx"

    [Enter] Continue
    [0] Back
    [00] Cancel & exit

  If a picked sheet has formulas that read from a sheet you
  did NOT pick, it is listed and you must choose:

    Linked to unselected sheets: 1
       1. "Bank Guarantee Report FY2026.xls"!Imp LC May26   :   uses "May26" (b1), not selected

    [1] Keep the link to the source file
    [2] Turn those formulas into plain values
    [0] Back
    [00] Cancel & exit

    [1]  formulas keep reading from the original file. The
         numbers update if that file changes, but the new
         workbook depends on it staying in the same place.
    [2]  those formulas are replaced by the number they show
         now. The new workbook stands on its own.
    [0]  go back and add the missing sheet (b1 above) instead.

STEP 6: Output
  A new file is created in the same folder:

    Combined_YYYYMMDD.xlsx   (e.g. Combined_20261117.xlsx)

  Same-day runs: Combined_20261117_1.xlsx, _2 ...

  Two sheets with the same name: the second gets _1, the
  third _2 ...      May26  ->  May26_1

  Formulas between sheets you picked together keep working
  inside the new workbook (they do not point back to the
  source file).

  Source files are never changed.

  If anything failed, the last screen offers
    [0] Save error log & close
  which writes error log_YYYYMMDD.txt to the folder. Send that
  file when asking for help.


----------------------------------------------------------------
  LIMITATIONS AND NOTES
----------------------------------------------------------------

  Hidden sheets   : Not listed, cannot be picked. A picked
                    sheet that reads from a hidden sheet is
                    flagged in Step 5 like any unpicked sheet.

  Ranges          : One file at a time. a1-a4 / a1-4 work;
                    a1-b4 does not - list them separately.

  Previous output : Combined_*.xlsx files in the folder are
                    listed in Step 3 like any other file.

  Macros (.xlsm)  : Sheets are copied, macros are not - the
                    output is .xlsx. Macros in source files
                    never run.

  Password files  : Listed as unreadable in Step 4; the script
                    does not ask for the password.


----------------------------------------------------------------
  FOR DEVELOPER
----------------------------------------------------------------

  Dependencies
  ------------
  - win32com.client (pywin32)
  - Microsoft Excel installed

  Excel Instance
  --------------
  DispatchEx, not Dispatch: Dispatch attaches to the user's
  running Excel, and Quit() with DisplayAlerts off would close
  their unsaved work. AutomationSecurity = 3 stops source
  macros running on open. Calculation is set to manual after
  the first Open and back to automatic before the output is
  saved (the mode is stored in the file).

  Reading Sources
  ---------------
  Only files picked in Step 3 are opened (read-only,
  UpdateLinks=0, dummy Password so protected files raise
  instead of prompting). Each stays open until the end and is
  reused when the user goes back. While open, each visible
  worksheet's UsedRange.Formula is read once and scanned
  (REF_RE) for references to other sheets in the same file.
  ~$ lock files are skipped.

  Copy
  ----
  Sheet.Copy(Before=placeholder) into a one-sheet new workbook,
  then renamed to its final name. Final names are worked out
  before the copy (case-insensitive, 31-char limit, _1, _2...).

  Relinking
  ---------
  Copying one sheet turns its references to other sheets into
  external links to the source file. After SaveAs, each source
  is relinked with ChangeLink(source -> output itself), which
  resolves by sheet NAME. So copies briefly take their source
  names (other sheets holding those names step aside to temp
  names), ChangeLink runs, then names are restored; renames
  update formulas automatically.

  ChangeLink must not run while a referenced sheet is missing:
  tested on May26 - it silently pointed at the OTHER file's
  May26 sheet. So:
    keep   -> that source is not relinked at all
    values -> cells whose formula hits a missing sheet are
              set to their own value first, then relinked

  Output Naming
  -------------
  Combined_YYYYMMDD.xlsx is a deliberate choice over the
  no-date deliverable rule. get_unique_path() adds _1, _2...


----------------------------------------------------------------
  ENVIRONMENT SETUP (one-time only)
----------------------------------------------------------------

  Python Version
  --------------
  Python 3.8 or above

  Required Package
  ----------------
  Run once in Command Prompt:

    pip install pywin32

  Microsoft Excel must be installed on the machine.


----------------------------------------------------------------
  TROUBLESHOOTING
----------------------------------------------------------------

  Error / Symptom                    Cause / Fix
  --------------------------------   ----------------------------------------
  Window opens and closes instantly  pywin32 not installed
                                     Run: pip install pywin32

  No Excel files found               Files must be in the SAME folder
                                     as Combine Excel Tabs.py

  Sheet not in list                  Sheet is hidden - unhide in Excel first

  Excel.exe left in background       Console was force-closed mid-run
                                     Use Office Process Checker to kill it
